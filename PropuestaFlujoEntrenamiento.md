# OlympX MVP 2026 - Propuesta de Flujo de Entrenamiento

> Documento para presentar al cliente. Define el flujo recomendado para registrar entrenamientos de forma simple para usuarios no expertos.

## 1. Resumen Ejecutivo

La forma mas facil de registrar entrenamiento para un usuario no experto es separar el proceso en 2 momentos:

1. Crear la sesion de entrenamiento.
2. Registrar ejercicios, series, repeticiones, peso y esfuerzo durante la sesion.

Este enfoque reduce friccion, evita formularios largos al inicio y refleja mejor como entrena realmente una persona en el gimnasio.

## 2. Recomendacion

### Flujo recomendado

- Pantalla 1: `Registrar entreno`
  - nombre de la sesion
  - plantilla rapida (Push, Pull, Legs)
  - musculos o zonas trabajadas
  - duracion estimada
  - intensidad general
  - notas opcionales

- Pantalla 2: `Detalle de entreno`
  - agregar ejercicios uno por uno
  - registrar series, repeticiones y peso
  - habilitar opciones avanzadas como esfuerzo y reps en reserva
  - ver resumen de volumen, sets y progreso

## 3. Por Que Es La Mejor Opcion

- Es mas facil para usuarios no expertos.
- Evita que el home se convierta en un formulario largo.
- Permite registrar el entrenamiento mientras se hace, no antes.
- Se parece al flujo real de entrenamiento: primero defines la sesion, luego registras cada ejercicio.
- Facilita seguimiento completo sin obligar al usuario a entender tecnicismos desde el primer paso.

## 4. Interpretacion Simple De Los Datos

| Concepto | Significado en la app |
|----------|------------------------|
| Sesion / entreno | El bloque completo de la visita al gimnasio |
| Ejercicio | Movimiento especifico dentro de la sesion |
| Serie / set | Repeticion de trabajo de un ejercicio |
| Repeticiones | Cuantas veces se ejecuta el movimiento |
| Peso / carga | Resistencia utilizada en el set |
| Esfuerzo | Que tan duro se sintio el set |
| Reps en reserva | Cuantas repeticiones quedaban disponibles |

## 5. Criterio De Producto

Para el usuario final, el flujo correcto no es “crear todo de una vez”, sino:

- iniciar la sesion en una pantalla simple,
- registrar el trabajo real a medida que avanza,
- y terminar con un resumen claro del entrenamiento.

## 6. Alcance Recomendado Para MVP

### Debe incluir

- Creacion de sesion con nombre y plantilla.
- Seleccion de grupos musculares o foco.
- Registro de ejercicios en detalle.
- Registro de sets con peso y repeticiones.
- Opciones avanzadas para esfuerzo y reps en reserva.
- Resumen final de la sesion.

### No debe incluir por ahora

- Programacion de rutinas complejas por semana.
- Analitica avanzada de periodizacion.
- Automatizacion por IA.
- Recomendaciones clinicas o de salud.

## 7. Propuesta Para Presentar Al Cliente

> La app va a guiar al usuario con un flujo simple: primero crea su entreno en una pantalla liviana y luego registra cada ejercicio con sus series, repeticiones y peso durante la sesion. Asi evitamos formularios pesados y hacemos que la experiencia sea clara incluso para personas que no dominan terminologia tecnica.

## 8. Conclusión

La mejor experiencia para OlympX es un flujo guiado y progresivo: sesion primero, detalles de ejercicios despues. Eso permite un seguimiento completo del entrenamiento sin exigir que el usuario entienda todo desde el inicio.
