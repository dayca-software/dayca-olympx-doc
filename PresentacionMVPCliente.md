# OlympX - Presentacion MVP Cliente

> Documento ejecutivo para mostrar al cliente la estructura del equipo y el plan de entrega del MVP.

## 1. Objetivo

Visualizar de forma simple:

- Quien participa en el MVP.
- Como se reparte el trabajo.
- En que orden se entregan las piezas clave.

## 2. Documentos De Apoyo

- `OrganigramaMVP.md`
- `CartaGanttMVP.md`
- `PropuestaMVP2Meses.md`
- `ResumenEjecutivoPO.md`
- `Estructura por etapas.md`

## 3. Alcance Visual Del MVP

- Login y registro.
- Perfil basico.
- Seleccion de gimnasio.
- Biblioteca de ejercicios.
- Registro de entrenamientos.
- Historial y PRs.
- Rangos de fuerza.
- Comparacion de progreso y nivel.
- App mobile con experiencia principal.

## 4. Fuera Del MVP Inicial

- Feed social completo.
- Rankings avanzados.
- Conquistas complejas.
- Notificaciones push avanzadas.
- Monetizacion premium completa.

## 5. Nota De Lectura

Este documento es de presentacion comercial. La definicion visual y cronograma siguen en `OrganigramaMVP.md` y `CartaGanttMVP.md`.
