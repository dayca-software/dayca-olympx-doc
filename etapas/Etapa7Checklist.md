# Etapa 7 - Checklist QA, Estabilizacion y Cierre

> Criterio minimo para considerar cerrada la Etapa 7.

## Entregables esperados

- Pruebas funcionales e integracion.
- Correccion de bugs.
- Estabilizacion productiva.
- Coordinacion general.

## Cobertura actual

- Smoke tests en API, web y admin.
- Typecheck y format funcionando en varios subproyectos.
- Contrato y backend ya bastante alineados.

## Pendientes de cierre

- Suites de integracion reales.
- E2E del flujo principal.
- Cobertura mas util en web/admin/mobile.
- Criterios de regresion antes de considerar release estable.

## Criterio de aprobacion

- Los flujos core deben tener prueba automatizada.
- Las apps deben pasar typecheck y smoke de forma consistente.
- El producto debe estar estable para continuar con nuevas fases sin arrastrar deuda critica.
