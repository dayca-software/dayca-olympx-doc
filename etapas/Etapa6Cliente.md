# Etapa 6 - Resumen para Cliente

## Estado

**Parcial baja.**

## Entregables cubiertos

- Perfil con estadísticas básicas.
- Base de notificaciones y moderación.
- Estructura para reaccionar a eventos del producto.

## Entregable pendiente

- Conquistas automáticas.
- Notificaciones push reales.
- Integración completa con PRs y rankings.

## Alcance minimo validado

- Ver estadísticas del perfil.
- Tener la base preparada para activar alertas y conquistas.

## Criterio de cierre

- El sistema debe poder reconocer eventos competitivos y convertirlos en logros o avisos.
- La experiencia debe ser visible para el usuario sin depender de procesos manuales.

## Nota

La Etapa 6 todavía no está lista para cierre formal porque las conquistas y las notificaciones siguen en una base inicial.
