# Etapa 4 - Rutinas Y Registro De Entrenamiento

## Estado

La funcionalidad está implementada y validada con tests locales. El cierre de release requiere
ejecutar el flujo completo en dispositivos Android/iOS físicos y aplicar la migración en staging.

## Entregables

- [Especificación técnica](./01-especificacion-tecnica.md)
- [Resumen para usuario](./02-resumen-para-usuario.md)

## Criterio de cierre

- Crear y editar rutinas persistentes.
- Asignar días semanales y seleccionar el día al iniciar una rutina.
- Registrar sesiones y sets con peso, repeticiones, RPE, RIR y notas.
- Finalizar y consultar el resumen de una sesión.
- Consultar el historial paginado.
- Continuar una sesión sin conexión y sincronizarla al recuperar conectividad.
