## Criterio De Aprobacion

- Los flujos principales se pueden recorrer de principio a fin.
- Cada pantalla tiene estado normal.
- Las pantallas que dependen de datos contemplan loading, empty y error.
- El prototipo no mezcla funcionalidades de social, rankings o conquistas de etapas posteriores.

## Pendiente De Cierre
