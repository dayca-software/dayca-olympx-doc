# OlympX - Paquete De Entregables

> Indice de los entregables organizados por etapa del MVP.

## Proposito

Esta carpeta reúne la documentación que puede entregarse al cliente o utilizarse como respaldo de
avance. Los documentos técnicos detallados permanecen en `doc/` y se enlazan desde cada etapa para
evitar duplicar fuentes de verdad.

## Estructura

| Carpeta                 | Etapa                                  | Estado                                                |
| ----------------------- | -------------------------------------- | ----------------------------------------------------- |
| [`etapa-1`](./etapa-1/) | Discovery, planificación y UX/UI       | Parcial: falta cerrar prototipo navegable             |
| [`etapa-2`](./etapa-2/) | Backend, base de datos y autenticación | Casi completa: falta hardening y validaciones finales |

## Documentos Base

- [`AnexoMVP.md`](../AnexoMVP.md): alcance, horas, costos y criterios de cierre.
- [`CartaGanttMVP.md`](../CartaGanttMVP.md): cronograma y avance ejecutivo.
- [`AvanceEtapas.md`](../etapas/AvanceEtapas.md): estado real por etapa.
- [`MatrizDocumentacion.md`](../MatrizDocumentacion.md): reglas para mantener la documentación.

## Regla De Actualización

- El contenido de esta carpeta resume y evidencia cada entrega.
- Los requisitos funcionales se actualizan en `BaseRequerimientos.md`.
- La arquitectura y los datos se actualizan en sus documentos técnicos respectivos.
- El avance se actualiza en `AvanceEtapas.md` y `CartaGanttMVP.md`.
